# 地缘关系如何生成乡土社会的权力与秩序——《乡土中国》的整合性论述

## 一、问题的提出：为何以“地缘”为切口

在《乡土中国》的概念群中，“地缘”常被当作“血缘”的附属项处理——费孝通本人的著名判断即是“在稳定的社会中，地缘不过是血缘的投影”。若止步于此，地缘关系似乎只是血缘关系的空间注脚，难以独立承担解释力。但一旦把提问方式改为**“乡土社会中的权力与秩序如何生成”**，地缘就不再是注脚，而成为整个解释链条的枢纽：正是因为人与地在空间上被固定下来，教化权力才可能以“长老统治”的形式持续再生产；正是因为地缘与血缘高度合一，契约与同意权力才缺少生长土壤；也正是因为商业、集市、移民造成了地缘与血缘的分离，社会性质的转变才随之发生。

本文据此提出一个整合性论述框架：**地缘关系在《乡土中国》中存在“投影型地缘”与“契约型地缘”两种面貌，二者构成一个从合一到分离的连续谱；权力与秩序的类型差异，可以在很大程度上由这一连续谱上的位置来解释。** 在这一框架下，本文进一步纳入近年围绕差序格局的学术延伸（大传统—小传统二重性、自我主义诠释谱系、熟人社会圈与基层治理机制），讨论地缘逻辑在当代中国的延续与变形。

需要先行说明的是：本文对《乡土中国》原书论点的复述属于文本层面的既有共识；对诠释谱系与当代机制的讨论则属于学术研究中的竞争性解释，文中会明确区分。

## 二、文本基础：地缘关系的双重面貌

### 2.1 投影型地缘：地缘是血缘的空间延伸

《乡土中国》在“乡土本色”中把中国基层社会的特征概括为“土气”与不流动：人们“生于斯、长于斯、死于斯”，聚村而居，形成一个面对面（face-to-face）的熟人社会。在这种格局中，世代人口的繁殖被比喻为“一个根上长出的树苗，在地域上靠近在一处”，于是家族这个社群本身就包含了地域的涵义，乃至“村落这个概念可以说是多余的”。

至“血缘和地缘”一篇，这一逻辑被明确表述：在稳定的社会中，**地缘不过是血缘的投影**，“生，也就是血，决定了他的地”。由此派生出几个在权力与秩序层面极为关键的推论：

1. **“籍贯”是血缘关系在地域上的标记**，而非单纯的地理位置——地缘身份的实质是血缘身份的空间化。
2. **地缘边界即社群边界**，村落共同体对“外来者”（客边、新客）的排斥，本质上是血缘原则在空间上的排他性表达。
3. **地缘的稳定性构成秩序自我复制的前提**：只要人和地的因缘不被打破，社会继替就可以在既定轨道上世代重复。

### 2.2 契约型地缘：地缘从商业中生长出来

费孝通同时指出另一条线索：**地缘是从商业里发展出来的社会关系**；血缘是身份社会的基础，地缘是契约社会的基础，“从血缘结合转变到地缘结合是社会性质的转变，也是社会史上的一个大转变”。

其机制在于：在亲密无间的血缘社群内部，商业是难以存在的——交易以人情维持，“算账”“清算”几近于绝交的代名词。因此交换必须在血缘关系之外寻找空间，而集市、街集正是“陌生人”的集合，是以地缘而非血缘为纽带建立起来的、依托契约与合意的社会关系。

### 2.3 小结：一个“合一—分离”的连续谱

由此，地缘关系在《乡土中国》中不是一个单一变量，而是一条连续谱的两端：

| | 投影型地缘 | 契约型地缘 |
|---|---|---|
| 与血缘关系 | 高度合一，是血缘的空间投影 | 相对分离，血缘之外的关系 |
| 典型场域 | 村落、家族、“籍贯” | 集市、街集、商业往来 |
| 秩序基础 | 礼治、人情、教化 | 契约、合意、法理 |
| 权力形态 | 教化权力为主导 | 同意权力的生长空间 |
| 身份原则 | 先赋、继替 | 获致、交易 |

## 三、地缘关系如何塑造乡土社会的秩序生成

### 3.1 空间不流动 → 熟人社会 → 礼治秩序

乡土秩序的第一个特征是不依赖成文法而依赖“礼”。这一特征的地缘条件十分直接：**在一个人员不流动、世代相处的地方性社群中，行为规范可以通过世代经验累积并经由社会化过程传递，无须外在强制力的持续介入。** 礼治的前提是传统足以应付生活，而传统之所以有效，正因为它对应的是一个变化缓慢、边界清晰、成员稳定的地缘空间。

### 3.2 地缘边界 → 内外之别 → 无讼与“意会”规则

乡土秩序的另一特征是“无讼”：纠纷倾向于在社区内部以调解、评理的方式消解，而非诉诸司法。这一取向的地缘基础在于，社区的长期共存使当事双方必须继续在同一空间内生�活与往来，因此“把事说清楚”“把账算清”反而构成关系的破坏。也就是说，**地缘上的不可退出性，使秩序的维持必须兼容关系的持续性**，这与契约社会中“交易结束即关系结束”的逻辑截然不同。

有研究据此指出，差序格局所揭示的“推己及人、依次向外伸缩”的“熟人社会圈”中，“意会”规则的理解意义重大，需深入发掘历史与现实资源。这一判断把“无讼”从一种规范性偏好，转换为一种在地缘约束下具有功能合理性的治理技术。

### 3.3 地缘投影 → 先赋身份 → 秩序的自我复制

当地缘是血缘的投影时，个人在秩序中的位置在其出生时便已基本确定。秩序生成因而主要表现为**继替**而非**变迁**：秩序的再生产无须依靠外部强制，只需依靠稳定的人口与土地关系和社会化的代际传递。这也解释了乡土社会秩序的“低成本”特点——它的维持成本被分摊在漫长的日常互动与世代传递之中。

## 四、地缘关系如何塑造乡土社会的权力生成

### 4.1 教化权力（长老统治）的地缘前提

《乡土中国》区分了横暴权力（基于冲突与强制）、同意权力（基于合作与契约）与教化权力（基于社会继替）。其中**教化权力是乡土社会的主导形态**，它以文化传统的延续性为合法性来源。教化权力的成立条件恰是地缘固定：只有在人员不流动、生活经验可以完整传递的社区中，年长者的经验才具有稳定权威，长老的裁断才具有天然的正当性。因此可以说，**地缘上的稳定性是教化权力的隐形制度基础**。

### 4.2 横暴权力的“无为”边界与同意权力的匮乏

横暴权力在乡土社会中并非不存在，但其渗透是有限的。农业经济的剩余有限，使得自上而下的强制统治缺乏足够的资源支撑，从而呈现出“无为政治”的面貌；而地方性自足又进一步降低了中央权力下沉的必要性与可能性。与此同时，**由于人群之间缺少基于合意的契约性联结，同意权力在乡土社会内部的发展空间被压缩**——这正是地缘与血缘合一所带来的权力格局后果。

### 4.3 差序格局的伸缩性与权力运作的“关系化”

差序格局的核心是以“己”为中心、按亲疏远近向外推展的、可伸缩的社会圈子，伸缩程度取决于中心“推”的能力。这一弹性在权力层面的后果是：**权力主体与权力对象的边界不是由职位或法条划定，而是由关系网络划定**；同一项要求在圈内与圈外会得到完全不同的对待。费孝通据此指出，以己为中心向内推产生“自我主义”（“一个人为了自己可以牺牲家，为了家可以牺牲党……”），向外推则产生“克己主义”（“克己也就成了社会生活中最重要的德性”）。他把中国人的自我主义定位为“事实上的公式”而非“应该的公式”，并认为“仁”作为私人关系中道德要素的共相，因缺乏具体性的“团体”而难以清晰。

### 4.4 地缘松动处的权力新形态

当地缘从血缘中分离——如商业集镇、移民、流动——同意权力便获得了生长条件：交易双方以对等地位缔结契约，秩序由合意而非教化保证。费孝通并将社会变迁情境下出现的新型权力称为“时势权力”，它源于对新局面的适应能力，与教化权力形成张力。**换言之，权力类型的更替，与地缘关系脱离血缘的程度高度相关。**

## 五、学术延伸 I：差序格局的“大传统—小传统”二重性

近年一项重要诠释（陈占江）提出，差序格局是一个兼具大传统与小传统双重意涵的概念：

- **大传统**以“克己主义”为内核，表达儒家道德理想（克己复礼、推己及人、修齐治平、天下为公）；
- **小传统**以“自我主义”为内核，是绝大多数普通人在日常实践中奉行的逻辑（公与私的紧张、“各人自扫门前雪”）。

该诠释强调，二者并非简单的上下分层关系，而是“你中有我、我中有你”却又互不统摄、互相否定的关系，使中国文化成为一个相容相克、极具张力的二重性系统。更具解释力的是其关于现代性的判断：**在百余年的反传统与现代化过程中，大传统意义上的差序格局被工具理性解构，而小传统意义上的差序格局却在权力与资本的共谋机制中被不断再生产，并深嵌于中国现代性之中，成为其萌发、生成与扩展的资源、规则和逻辑。**

该文亦注意到费孝通晚年对克己主义层面的强调，及其以儒家伦理化解现代性危机、重建道义秩序的呼吁。作者据此提出两个尚待解决的问题：费孝通对儒家的理解是否止于自我主义层面？以及是否应将差序格局放回其“文化传统与现代化”的终身关怀与思想脉络中加以把握。

**对本文主题的意涵**：若地缘—血缘合一的秩序结构并未随现代化而消失，而是以“小传统”形态被权力与资本的互动持续再生产，那么“地缘关系影响权力与秩序”就不是一个仅属于传统乡村的命题，而是一个仍然活跃的现代性命题。

## 六、学术延伸 II：围绕“自我主义”的诠释谱系及其争议

### 6.1 第一类诠释模式

数十年来社会学、人类学、心理学围绕差序格局形成了大量诠释。其中在“自我主义”层面理解差序格局并作延伸性解读的代表性观点包括：黄光国的“人情与面子”模型、孙立平的“稀缺资源配置论”、阎云翔的“差序人格论”、翟学伟的“权力再生产论”、张江华的“卡里斯玛论”、肖瑛的“新差序格局论”。这些观点尽管彼此存在分歧，却在“费孝通对差序格局持自我主义论”这一点上形成共识。

### 6.2 对该共识的批评

- **吴飞**通过比较差序格局与丧服制度，认为从自我主义角度理解差序格局既偏差地解读了儒家伦理，也无法有效解释己身与家庭、家国天下的关系；
- **廉如鉴**认为自我主义解读既脱离中国传统社会的内在构造，也未充分重视传统伦理对中国人行为的塑造作用；
- **潘建雷、何雯雯**指出，将差序格局中的“己”定位为自我主义者，无法解释乡土社会的人心与社会结构如何实现一种统合的秩序；
- **沈毅**则认为，差序格局既描绘了儒家社会建构的基本框架，也呈现了现实人伦实践所具有的差序性特征，“义”与“利”之间既紧张又交融的混合关系构成差序格局的内在张力，但费孝通对差序格局的根本性质最终却判定为自我主义。

### 6.3 对权力与秩序命题的意义

这场争论并非纯粹的概念史辨析。若把“己”理解为自我主义者，那么乡土社会的秩序就只能依靠外部规范或利益博弈来解释，其“统合性”便难以说明；若把“己”理解为处在伦理关系中的道德主体，则秩序可以被理解为由内而外的推展过程。**两种解读直接对应两种秩序生成模型：外部约束型与内生化型。** 这构成后续研究最有价值的分歧点之一。

## 七、学术延伸 III：转型中国的“熟人社会圈”与基层治理机制

### 7.1 熟人社会圈的延续与“意会”规则

有文献从经典与现实之间诠释的角度指出，“差序格局论”揭示的不仅是中国传统社会，转型中国社会的内核也始终是一个“推己及人”、依次向外伸缩逐渐扩张的“熟人社会圈”，在其中“意会”规则的理解具有重要意义，需深入发掘历史与现实资源。相关研究亦强调，自解放以来，中国社会特别是中国农村——这个曾经最符合费孝通笔下“差序格局”的乡土社会——发生了最为剧烈的社会转型与变迁，传统与现代、本土与外来的张力构成其研究背景。

### 7.2 “连带式制衡”：基层权力运作的地缘—关系基础

一项关于基层组织权力运作机制的研究提出了“连带式制衡”概念，揭示了中国基层组织在非正式或半正式治理实践中的内在机制及其社会基础与价值基础，并发现**村级组织在国家权力体系中的位置构成乡村治理的部分外部条件**。

这一发现与《乡土中国》的地缘逻辑形成呼应：在正式制度供给不足或不适配的地方，治理依靠的是关系网络中的相互牵制与责任连带，而这种关系网络的载体恰恰是地缘上高度重叠的熟人社会。换言之，地缘关系在此不是背景，而是治理机制得以运转的**操作层**。

## 八、整合性命题

综合文本与学术延伸，本文提出以下四条可检验的命题：

1. **替代命题**：地缘与血缘的合一程度越高，教化权力在权力结构中的比重越大，同意权力的空间越小。
2. **边界命题**：地缘边界的清晰与不可退出性，使秩序维持倾向于“无讼”与“意会”，而非明文规则与外部裁决。
3. **分离命题**：地缘从血缘中分离（商业、集市、移民、城镇化）是社会性质转变的枢纽，也是契约、法理秩序与时势权力生长的条件。
4. **再生产命题**：在现代性条件下，地缘—血缘关系并非被简单消解，而是以大传统的解构与小传统的再生产双重方式，继续为基层权力运作提供规则与资源。

第 4 条命题与前述“大传统—小传统”二重性诠释、以及“熟人社会圈”“连带式制衡”的经验研究相互支持，但仍有待更大范围的实证检验，宜视为有较强理论依据的**待验证判断**，而非既成结论。

## 九、研究缺口与后续议题

1. **地缘的测量问题**。既有讨论多以“血缘—地缘”的二分或连续谱作定性描述，缺少可操作的量化指标（如居住稳定性、通婚半径、外出务工比例、社区成员更替率）。
2. **“己”的性质之争尚未收束**。自我主义论与儒家伦理统合论的分歧，直接影响秩序生成模型的构建，需要在经验层面设计判别性检验。
3. **大传统与小传统的互动机制**。二者“互不统摄、互相否定”的判断具有启发性，但其边界条件、转换机制与地域差异尚待厘清。余英时关于大传统源自民间并须回到民间、以及“地上”与“地下”小传统的区分，可作为进一步分析的资源。
4. **国家—地方关系的维度和层次**。村级组织在国家权力体系中的位置已被指出是乡村治理的部分外部条件，但地缘网络与正式权力之间的耦合与摩擦，仍需更细致的机制研究。
5. **比较视野**。地缘逻辑是否为中国乡土社会所独有，抑或是所有低流动性农业社会的通则，缺乏跨社会比较的检验。

## 十、结论

回到最初的问题：《乡土中国》中的地缘关系如何影响乡土社会的权力与秩序？

简要回答是：**地缘关系在乡土社会中主要不是独立变量，而是血缘关系的空间投影；正是这种“投影型地缘”构成了礼治秩序与教化权力的隐性制度基础，使秩序以继替而非变迁的方式低成本地自我复制，使权力运作依赖关系网络而非职位法条。而“契约型地缘”——从商业中生长出来的、以陌生人合意为基础的地缘关系——则是秩序与权力类型转换的临界点：从血缘结合到地缘结合，正是社会性质的大转变。**

进一步的学术延伸表明，这一逻辑并未随传统乡村的瓦解而终结。围绕差序格局的大传统—小传统二重性诠释、自我主义诠释谱系及其批评、以及“熟人社会圈”“意会”规则与“连带式制衡”等研究，共同指向一个判断：地缘—血缘关系在现代性中经历了“大传统被工具理性解构、小传统被权力与资本再生产”的双重命运。至于这一判断的确切边界与强度，仍属有待检验的开放问题。
